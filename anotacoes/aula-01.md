
#Aula 1 - Início do Projeto
- Mkdir nome da pasta
- cd nome da pasta
- .\venv\Scripts\Activate.ps1
- Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned (se der erro no terminal)
- Pip install flask
- pip freeze > requirements.txt (pip freeze, ele vai listar todas as bibliotecas Python instaladas no seu ambiente atual)
